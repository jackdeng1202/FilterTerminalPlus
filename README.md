# FilterTerminalPlus

串口日志过滤终端，PySide6 重写版。原版 FilterTerminal.exe（v0.95191，Borland C++Builder + CPort 2002 年作品）核心体验保留，修复其顽疾并加入现代功能。

## 特性

### 串口终端
- 波特率/数据位/校验/停止位可配（默认适配 RK3568 调试口 1500000）
- **自动重连**：拔掉 USB 串口板 / adb OTG 切换后自动关闭串口并静默重连，不再弹异常风暴
- **键盘透传**：可直接在终端里操作 vim/top/less；`Ctrl+C` 中断、`Ctrl+U` 清行、`Ctrl+Z` 挂起、`Ctrl+L` 清屏；复制文本用 `Ctrl+Shift+C`
- **ESC 互切**：任意焦点位置按 `ESC` = 连接/断开切换（全局快捷键）；终端内 `Shift+ESC` 才发送真正的 ESC 字节（0x1B）给设备
- `Ctrl+D` 本地清屏（终端 + 全部过滤窗一起清）
- F1–F12 预制快捷命令，点击按钮或直接按键发送；**快捷命令不进历史**
- 亮色/暗色主题切换

### 过滤窗（可开多个）
- **表达式语法只有一条：`|` 表示 OR（命中任一条件即可）**：`error|into home|"66"` 命中含 error、或含 `into home`、或含 `"66"` 的行
- **条件按原样字面匹配**：条件里的空格、引号都是内容的一部分——`into home` 只匹配连续出现 `into home` 的行（不是两个词），`"66"` 只匹配带引号的 66；没有 `&&`、括号、转义等其他语法
- 连续多个 `|`（如 `a||b`）视为一个 `|`；每个条件首尾空白自动去除（`a | b` 等价 `a|b`）
- **全词匹配**开关：命中处两侧不能是字母/数字/下划线/冒号/小数点——全词 `22` 不命中 `:22`、`10:22:33`、`192.168.1.22`
- **自动剔除内核时间戳**：设备自打印的行首 `[ 26.622]` 不参与匹配，只过滤真正内容
- 区分大小写开关；表达式错误红框内联提示（不弹框）
- 每窗独立"重放历史"（从最近 5 万行源缓冲全量重算）与"全屏"独占按钮
- 排列模式：上下分割 ↔ 标签独占右侧，随意切换

### 命令历史
- 只记录**真正发出去的命令**；`↑` 翻旧（第一下 = 刚发的命令，到最旧停住）、`↓` 滚轮反向翻新（越过最新清空回输入状态）
- 重复发送的命令自动去重并置为最新
- 40 条上限；下拉列表淡蓝色边框、与命令框留有间距；鼠标点选后 `↑` 从选中项继续往旧翻

### 其他
- **自动滚动暂停/恢复**：点击日志区暂停滚动（回看不跳），点命令输入框或发送命令立即跳回最新
- 窗口布局持久化：主窗口/过滤窗大小位置、排列模式、浮动状态，重启原样恢复
- 配置导出/导入 JSON（布局、快捷命令、过滤器全带走，换电脑即用）
- 日志记录（终端收发全文）+ 常驻诊断日志 `ftplus_app.log`

## 运行

源码运行（需 Python 3.10+ 与 PySide6）：

```bat
启动FilterTerminalPlus.bat
:: 或
python filterterminal_plus.py
```

### 打包绿色版

```bat
pip install pyinstaller
python -m PyInstaller FilterTerminalPlus.spec --noconfirm
:: 产物在 dist\FilterTerminalPlus\，压缩即用
```

## 测试

```bash
python test_filter_parser.py   # 过滤表达式解析器单元测试（40 例，不依赖 Qt）
```

## 文件说明

| 文件 | 用途 |
|---|---|
| `filterterminal_plus.py` | 主程序（全部功能） |
| `test_filter_parser.py` | 过滤表达式解析器单元测试 |
| `FilterTerminalPlus.spec` | PyInstaller 打包配置（窗口版） |
| `FTPlus_dbg.spec` | PyInstaller 打包配置（控制台调试版） |
| `启动FilterTerminalPlus.bat` | Windows 双击启动脚本 |
| `config.json` | 用户配置（运行时生成，不进版本库） |

## 配置说明

配置保存在程序目录 `config.json`（UTF-8 JSON），含串口参数、快捷命令、过滤器、历史命令、主题、窗口布局。程序关闭时自动保存；也可用菜单"导出配置"手动备份。
